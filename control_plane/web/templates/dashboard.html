What is a task?

A task is a single, concrete piece of work you hand to an agent — like "Research current AI trends" or "Write the FastAPI auth endpoints." Each task:

  • • Has a goal — what you want done
  • • Needs a capability — the skill an agent must have to do it
  • • Optionally belongs to a project, and counts toward its progress

Pick a capability that matches an available agent's skills, or the task can't be run.
